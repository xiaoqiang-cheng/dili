# 统一预览工作区

日期：2026-10-23。状态：实现及回归验收完成。

## 目标与交互

页面右侧提供唯一的预览工作区，替代资源管理器、随手记、网页服务各自占据布局空间的方式。主会话与底部终端继续保持现有功能。

- 顶部使用浏览器式标签栏，支持新建、切换、关闭与键盘操作；隐藏整个面板保留已打开标签。
- 资源管理器作为工作区标签打开，点击文件或 Git diff 后打开对应的独立标签；相同工作区／路径／预览类型重复打开时聚焦已有标签。
- 文件和差异绑定打开时的会话及目录，切换联系人不会改变其来源。资源管理器支持选择其他联系人的目录。
- 网页可同时打开多页，每页独立保存地址和浏览状态；继续使用现有直连能力，公网端口转发另见 TODO 23。
- 随手记沿用现有单份笔记、实时 Markdown、自动保存、冲突处理和草稿恢复；关闭标签不等于删除笔记，不新增多文档笔记系统。
- 切换或隐藏时保留已打开内容的组件实例，避免网页刷新、文件阅读位置丢失或随手记编辑状态重置；关闭普通标签后释放对应实例。
- 标签描述和面板宽度按设备链接在浏览器保存，刷新后恢复。笔记正文继续由现有服务保存，不放入标签元数据。
- 刷新恢复已打开文件和网页地址；网页内部未保存表单不跨刷新恢复。仅切换标签或隐藏面板时保留原实例。
- 桌面右侧并排，窄窗口使用右侧覆盖面板，手机占满可用工作区并提供返回按钮；统一拖动宽度，不再叠加三个独立宽度。

## 实施边界

复用现有 React、文件树、文件与媒体预览、DiffView、Vditor、iframe 及 Splitter，不替换现有编辑器或引入新的布局框架。分享页继续使用现有只读资源管理器，不扩大访问权限。当前服务承载开发会话，验收使用隔离端口、数据与构建目录，不重启活动服务。

## 验收

- 文件、diff、笔记、多个网页共存；去重、切换、关闭相邻标签及关闭最后一页正常。
- 切换联系人仍展示文件原始工作区；已删除／目录变化的会话不读取错误目录。
- 快速切换和关闭时迟到的文件请求不覆盖其他标签；读取失败可重试。
- 随手记在切换、关闭、隐藏及刷新后保持保存／恢复能力；网页切换不重新创建 iframe。
- 标签栏键盘导航、溢出滚动、窄屏、手机、主题和 200% 缩放可用；面板拖动不挤出横向页面滚动。
- 既有终端、HTML 沙箱、媒体、Git diff 和分享读取能力回归通过。

验收结果：`npm run verify` 类型检查通过、服务端 266 项通过／1 项跳过、隔离浏览器 182 项通过。已检查桌面、手机和深色主题截图；浏览器测试覆盖多网页实例保持、笔记跨标签保存、文件去重及来源隔离、迟到请求、错误重试、宽度记忆与手机 200% 缩放。公网真实站点的可达性及嵌入限制不属于本轮布局验收。
