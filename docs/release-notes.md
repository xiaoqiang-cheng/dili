## Dili 0.5.4 — DeepSeek Harness 结构化对话与远程链路收敛

### DeepSeek Harness 成为一等后端

- 结构化对话：原生历史、prompt、停止与问题卡片，和 Claude／Codex 共用同一套对话面板。阻塞式问题经 `$events` waterfall 回答，定时问题用 `userQuestions/answer`；图片输入对 dsh 纯文本 prompt 直接隐藏，不静默丢弃文件。
- 工具调用渲染为可展开卡片：按原生 `callId` 配对 `tool/call` 与 `tool/result`，缺结果保持「运行中」，出错保持「失败」，文本有长度上限。
- 原生设置：模型与权限读取 `session.modelCatalog`、`permissionPresets`／`catalog`、`projections`，经 `session.selectModel` 与 `/permission` 写入并回读确认；目录缺失或 TUI 持有会话时面板只读。
- 写入者归属：dsh-tui 持有会话时图形对话明确只读，提供显式交接按钮——停止 TUI 并在同一 native session 上转成 web writer；任务进行中或存在待处理请求时拒绝交接，不伪造“可发送”。
- 修复 dsh 0.2 会话可恢复性：新建联系人改用裸 UUID，旧联系人启动时用可达会话替换；群投递按每个联系人的 `executionTransport` 决定 web 还是终端。
- dsh 0.2 没有原生 auto 预设，移除该入口并明确标注不支持，已有 Auto 联系人归一为原生默认。

### 群聊

- 成员提出的请求（审批／提问）直接在群聊内显示并回答。
- 群工作区权限支持选择目录与成员批量授权，逐成员反馈，可只重试失败成员；不改变成员主目录，不中断任务。
- 群聊角标只统计群消息；成员异常与待审批单独用状态文字呈现，不再冒充未读。

### 通知

- 群回复计入应用角标，并播放「嘀哩嘀哩」提示音、弹出系统通知；成员一轮回复完成即视为其群回复，不重复计数。
- 窗口隐藏或失焦时不清除未读，获得焦点后补做已读；浏览器标签页图标可显示数字角标。
- 中继管理台可向单台设备推送通知（24 小时、每设备 20 条）；设备打开页面立即提示，无页面时等待下次连接。

### 中继

- 设备管理台：全部／在线／离线／已撤销计数与筛选，每台设备显示远程地址、中继端口、最近心跳、最近登录、生效限速、配对与撤销时间。
- 限速由中继强制下发给 frp，客户端请求的值不被采信。
- 设备可附加仅管理员可见的备注。
- **移除主机 P2P 上游。** `SESSIONDECK_RELAY_P2P_UPSTREAM` 的裸地址会对所有设备生效，三个不同的设备链接被路由到同一台机器；可达不等于身份。外网改回每设备独立的 FRP 端口，中继不再向任何上游探测。

### 远程访问

- 主机网页服务代理：公网 PWA 经主机侧 `/web-proxy/<token>/` 转发 HTTP 与 WebSocket，浏览器 origin 保持不变；dsh 原生界面自动使用，其他服务需在 `SESSIONDECK_WEB_PROXY_TARGETS` 中显式允许。
- 远程监听绑定私网地址时，用 `SESSIONDECK_REMOTE_ALLOW`（IP/CIDR）限制来源，HTTP 与 WebSocket 升级都校验；语音升级同样受来源限制。
- 切换机器时立即显示「正在切换到 X…」进度条，不再让旧页面僵住。
- 打开机器显著变快：哈希资源改为一年 `immutable` 缓存、外壳从缓存启动、旧 chunk 自动清理。

### 会话与工作台

- 会话信息显示原生 token 用量：Claude／Codex 从本地原生历史汇总，截断窗口标「最近窗口」；dsh 或旧记录没有用量字段时显示「原生未提供」，不按字数估算。
- 会话「更多」可导出独立 HTML 快照：纯文本转义、无脚本、带 CSP，包含原生工具调用卡片；演示模式、身份变化或没有可读记录时明确失败。
- 「更多 → 运行诊断」提供只读运行快照：进程、修订、补发窗口、会话、连接、终端、后端版本与数据目录，不含正文、令牌或凭据。
- 会话「更多 → 工作区权限」可追加原生目录权限：Codex 空闲时立即应用并回读确认，Claude 与兼容终端在下次恢复时通过 `--add-dir` 应用；Fork 继承附加目录。仅所有者可修改。
- 消息复制：三平台用户消息与助手回复统一提供复制按钮，保留原文、换行与缩进；修复 PWA 图形会话中用户消息无法选中复制、长按菜单失效的问题。
- 归档联系人时自动停止当前原生任务，停止失败保留联系人并显示原因；恢复归档不会自动启动。
- 返回最近看过的会话先显示内存快照再同步，发送、审批与设置仍等待实时确认。
- 预览面板支持全屏与目录独立浏览。

### 稳定性、性能与工程

- 状态流断线重连按 `Last-Event-ID` 只补连续补丁，缺口或超限才回退完整快照。
- 联系人每页 120 张、对话默认最近 200 条渐进渲染；长 Markdown 分块、代码高亮按需加载；隐藏页面暂停非必要轮询。可选 `SESSIONDECK_IDLE_SLEEP_MINUTES` 默认关闭。
- 修复 Codex 停止后残留 writer 导致桌面端无法接管会话。
- 修复 Claude 历史末尾尾部与过期游标错误配对导致消息丢失。
- 修复原生问题交接在普通回合结束后仍一直显示。
- 修复 dsh 分享协作模式下发送按钮不可用。
- 修复群消息发送成功后弹出多余成功提示。
- 发布包修复：`relay-notice-poller.ts` 曾被 `relay-*.ts` 误排除，安装后服务无法启动；CI 的 PWA job 未安装 WebKit。
- CI 拆分为 `unit`、`e2e`、`pwa`、`package` 四个并行 job，失败分别上传制品。
- 新增 `docs/agents/` 领域笔记、浏览器基线静态扫描，以及大量纯函数单测（排序、Markdown 分块、用量、导出、SSE 补发、休眠、shell 引号、i18n 等）。

### 下载

- `dili-pwa-0.5.4-all-platforms.tar.gz`：独立静态 PWA，解压部署在 HTTPS 域名根目录，浏览器打开后安装。
- `dili-0.5.4-linux-x86_64.tar.gz`：机器端工作台，需要 Node.js 24+。
- `dili-relay-0.5.4-linux-x86_64.tar.gz`：中继服务包，仍需配置 TLS/Caddy/frps。
- `dili-workbench-0.5.4.tgz`：npm 格式安装包，未发布到 npm registry。
- `SHA256SUMS`：下载校验值。

### 升级注意

- 中继不再读取 `SESSIONDECK_RELAY_P2P_UPSTREAM`：从服务配置中删除它，并按 `npm run build:relay` 更新 `relay.mjs` 后重启。若曾在云服务器上部署 EasyTier／WireGuard 主机隧道，现在已无代码使用，可停用并回收。
- 设备链接仍是每设备独立端口；FRP、邀请码、设备撤销语义不变，不需要重新配对。

### 当前限制

dsh 的审批仍没有可用的 Web 回答 RPC，审批在原生界面完成，图形对话只读展示。dsh 原生沙箱只支持单工作区。PWA 不是原生 APK/IPA/EXE；机器列表仅保存在当前浏览器/安装实例，不跨设备同步。PWA 入口自动化覆盖 Chromium 与 iPhone WebKit 设备描述，工作台回归使用 Chromium，不能替代真机安装、后台恢复、麦克风与跨域跳转验收。完整说明见包内 INSTALL.md 或 docs/pwa.md。

中继流量统计为整台服务器网卡流量，不是单设备用量；历史只保留内存中最近 30 分钟，重启清空。

## Dili 0.5.3 — 多机器切换与中继监控

- PWA 顶部提供紧凑机器切换条，保留返回机器列表入口，恢复每台机器最近访问页面。
- 群成员头像可进入私聊；未主动 @ 时默认接续最近回复的成员。
- 群聊支持归档、恢复和持久化，保留成员与消息；长记录提供明确滚动条。
- 中继管理员仪表盘显示服务器入站/出站速率、30 分钟趋势、带宽利用率、MB/s 纵轴和 1 MB/s 参考线。
- 优化版本提示和 iPhone 输入法收起后的布局恢复；修复编辑器网络隔离测试受版本查询干扰的问题。

### 下载

- `dili-pwa-0.5.3-all-platforms.tar.gz`：独立静态 PWA，解压部署在 HTTPS 域名根目录，浏览器打开后安装。
- `dili-0.5.3-linux-x86_64.tar.gz`：机器端工作台，需要 Node.js 24+。
- `dili-relay-0.5.3-linux-x86_64.tar.gz`：中继服务包，仍需配置 TLS/Caddy/frps。
- `dili-workbench-0.5.3.tgz`：npm 格式安装包，未发布到 npm registry。
- `SHA256SUMS`：下载校验值。

### 当前限制

PWA 不是原生 APK/IPA/EXE；不同来源的机器可能由系统浏览器打开。机器列表仅保存在当前浏览器/安装实例，不跨设备同步。实际会话与语音需要机器在线及相应权限。PWA 入口自动化覆盖 Chromium 与 iPhone WebKit 设备描述；工作台回归使用 Chromium。它们不能替代 Android/iPhone 真机安装、后台恢复、麦克风与跨域跳转验收。完整说明见包内 INSTALL.md 或 docs/pwa.md。

中继流量统计为整台服务器网卡流量，不是单设备用量。建议指定公网网卡，按实际购买带宽配置上限；历史只保留内存中最近 30 分钟，重启清空。
